### 1. ส่วนใดของงานที่ฉันใช้ AI ช่วยมากที่สุด เพราะอะไร

ส่วนของงานที่ฉันใช้ AI ช่วยมากที่สุดคือ **การเขียน JavaScript สำหรับจัดการ DOM และ logic ในการเชื่อมโยงข้อมูลกับ localStorage** เช่น ฟังก์ชันการเปลี่ยนสถานะปัญหาในโหมดเจ้าหน้าที่ (F4) การสร้างเลขที่แจ้งอัตโนมัติ (FIX-2026-XXXX) และการคำนวณสัดส่วนปัญหาเพื่อสร้างกราฟแท่งด้วย CSS `%` ในหน้า Dashboard (F6) 

เหตุผลที่ใช้ AI ในส่วนนี้มากที่สุด เนื่องจากเป็นส่วนที่มีเงื่อนไข logic ค่อนข้างซับซ้อน ต้องมีการดึงข้อมูลจาก `data/issues.json` มารวมกับข้อมูลใหม่ใน `localStorage` การให้ AI ช่วยร่างโครงสร้างโค้ดฟังก์ชันเริ่มต้น (Boilerplate code) และช่วยอธิบายแนวทางการใช้ event listeners ช่วยลดเวลาในการลองผิดลองถูก ทำให้เห็นลำดับการทำงานของโค้ดได้ชัดเจนและรวดเร็วขึ้น

### 2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร

มีเหตุการณ์ที่ AI ให้คำตอบไม่ตรงโจทย์อย่างชัดเจนในตอนที่ขอคำแนะนำในการทำหน้า **Dashboard สรุปภาพรวม (F6)** โดย AI พยายามเสนอโค้ดที่เรียกใช้ **Chart.js Library** เพื่อสร้างกราฟ 

ฉันทราบทันทีว่าคำตอบนี้ผิดเงื่อนไข เพราะได้ศึกษาข้อกำหนดทางเทคนิค **T9 (ห้ามใช้ Framework และ Library ทุกชนิด ต้องใช้ Vanilla HTML/CSS/JS เท่านั้น)** ฉันจึงทำการแก้ไขโดยปฏิเสธโค้ดชุดนั้น และปรับ Prompt ใหม่โดยระบุข้อจำกัดอย่างชัดเจนว่า *"เขียนด้วย Vanilla JavaScript และคำนวณสัดส่วน % เพื่อกำหนด inline style width บน element เท่านั้น ห้ามใช้ external library"* จากนั้นนำโค้ดที่ได้มาตรวจทาน ปรับแต่งโครงสร้าง CSS Flexbox/Grid และทดสอบการคำนวณสัดส่วนเปอร์เซ็นต์ด้วยตนเองจนแน่ใจว่าทำงานได้ถูกต้องและเป็นไปตามข้อกำหนด

### 3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว

หลังจากการทำโปรเจกต์นี้ ฉันมีความเข้าใจลึกซึ้งและสามารถทำได้ด้วยตนเองในเรื่อง **การจัดการ DOM Events, การใช้ `fetch()` API ดึงข้อมูลจากไฟล์ JSON และการวางโครงสร้าง Semantic HTML5 ร่วมกับ Accessibility (T1-T3)** 

ตอนนี้ฉันสามารถเขียน HTML โดยใช้ Landmark elements (`<header>`, `<main>`, `<nav>`, `<section>`) และวางลำดับ Heading `<h1>`-`<h6>` ได้ถูกต้องทุกหน้า ผูก `<label>` กับ `<input>` พร้อมทำ Form Validation ด้วยทั้ง HTML Attributes และ JS error messages รวมถึงการทดสอบให้ผ่านเกณฑ์ Lighthouse Accessibility $\ge 90$ นอกจากนี้ยังสามารถเขียน JS วนลูปสร้าง DOM elements เพื่อแสดงรายการปัญหาและทำ Responsive Layout ด้วย CSS Custom Properties และ Flexbox/Grid ได้ด้วยตนเองโดยไม่ต้องคอยเปิดถาม AI อีกต่อไป
