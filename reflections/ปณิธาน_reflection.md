# AI Reflection (ปณิธาน)
**รายวิชา SC17332 - Mini Project Smart Campus (กลุ่มที่ 6 - Campus Fix-It)**

**1. ส่วนใดของงานที่ผมใช้ AI ช่วยมากที่สุด เพราะอะไร**
ส่วนที่ผมใช้ AI ช่วยมากที่สุดคือการเขียนสคริปต์ JavaScript ในหน้าแจ้งปัญหาและการเชื่อมต่อข้อมูล JSON เพราะว่าผมยังมีข้อสงสัยในการเขียนโค้ดเพื่อให้เป็นไปตามกฎที่เคร่งครัด เช่น การดึงข้อมูลด้วย fetch (T7) และการเก็บลง localStorage ให้ข้อมูลไม่หายหลังรีเฟรช รวมถึงการดัดแปลง FileReader สำหรับอัปโหลดภาพแบบ Base64 ซึ่งมีความซับซ้อนสำหรับผม AI ช่วยเสนอโค้ดโครงร่างและให้คำอธิบายที่ช่วยให้ผมเข้าใจหลักการทำงานของ DOM และ Event Listener ได้รวดเร็วกว่าการหาข้อมูลเอง ทำให้มีเวลาไปโฟกัสที่ความถูกต้องของข้อมูลจริงและ Accessibility มากขึ้น

**2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ผมรู้ได้อย่างไรและแก้ไขอย่างไร**
มีเหตุการณ์ที่ AI ให้คำตอบไม่ตรงกับเกณฑ์โจทย์ โดยแนะนำให้แทรก CSS ผ่านทาง JavaScript (Inline Style) ซึ่งขัดกับข้อกำหนด T4 อย่างชัดเจน นอกจากนี้ AI ยังให้โค้ดที่มีการอ้างอิง Path โฟลเดอร์รูปภาพผิด (`images/` เป็น `image/`) และใส่โค้ดเรียกไฟล์สคริปต์ซ้ำซ้อนจนหน้าเว็บไม่ดึงข้อมูล ผมรู้ได้จากการตรวจสอบโครงสร้างโฟลเดอร์จริงในเครื่องและเทียบคะแนนกับไฟล์ PDF ข้อกำหนด การแก้ไขคือผมสั่ง Prompt ให้ AI ถอด Inline Style ออกไปเขียนในไฟล์ `style.css` เท่านั้น และสั่งให้แก้ไข Path รูปภาพพร้อมลบโค้ดส่วนที่ซ้ำซ้อนออกจนระบบทำงานได้ปกติ

**3. หลังทำโปรเจกต์ มีเรื่องใดที่ผมเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว**
ผมเข้าใจโครงสร้าง Semantic HTML (T1) และหลักการจัด Layout ด้วย CSS Flexbox/Grid (T4-T5) มากขึ้นอย่างชัดเจน ตอนนี้ผมสามารถสร้างโครงสร้างหน้าเว็บที่มี Header, Nav, Main และ Footer รวมถึงการจัดปุ่มและฟอร์มให้อยู่กึ่งกลาง หรือเรียงการ์ดแบบ Responsive ได้ด้วยตนเอง นอกจากนี้ยังเข้าใจหลักการจัดการตัวแปร DOM พื้นฐานใน JavaScript เช่น การดึงข้อมูล input และการเปลี่ยน textContent ได้โดยไม่ต้องพึ่งพาโค้ดจาก AI ทั้งหมดแล้ว
