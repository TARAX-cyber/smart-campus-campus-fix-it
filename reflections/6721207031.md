AI Reflection รายบุคคล

ชื่อ-นามสกุล: นนทพัตร ไววิธี 
รหัสนักศึกษา: 6721207031  
กลุ่ม: กลุ่มที่ 6-Campus Fix-It ระบบแจ้งปัญหาและติดตามการซ่อมภายในมหาวิทยาลัย  

1. ส่วนใดของงานที่ใช้ ai ช่วยมากที่สุด เพราะอะไร
หัวข้อระบบ Campus Fix-It นี้ ผมใช้ AI ช่วยมากที่สุดในส่วนของการออกแบบโครงสร้างและเขียนฟังก์ชันตรรกะใน JavaScript สำหรับสร้างระบบ Carousel แยกตามหมวดหมู่ปัญหาอัตโนมัติ และการจัดการระบบบันทึกข้อมูลลง localStorage เนื่องจากในช่วงเริ่มต้นของการพัฒนา โค้ดส่วนนี้ค่อนข้างมีความซับซ้อนในการจัดการข้อมูลแบบอะซิงโครนัส การดึงข้อมูลจาก issues.json มาจับคู่กับข้อมูลใหม่ และการคำนวณการเลื่อนตำแหน่งหน้าจอด้วย Vanilla JavaScript ให้แสดงผลได้อย่างลื่นไหลโดยปราศจากการใช้ Library ภายนอก การให้ AI ช่วยร่างฟังก์ชันตั้งต้นและอธิบายแนวคิด จึงช่วยประหยัดเวลาและทำให้ผมเข้าใจวิธีประยุกต์ใช้ DOM Manipulation

2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์และแก้ไขอย่างไร
มีเหตุการณ์ที่ AI ให้คำตอบไม่ตรงกับข้อกำหนดของรายวิชา เช่น ตอนที่ผมให้ AI ช่วยเขียนฟังก์ชันกรองข้อมูลปัญหาและเรียงลำดับ โค้ดที่ AI สร้างขึ้นมาในตอนแรกแอบแทรกการเรียกใช้งาน jQuery มาให้ ซึ่งขัดกับกฎเหล็กของรายวิชาที่บังคับให้ใช้ HTML, CSS และ JavaScript ล้วนเท่านั้น ผมรู้ได้ทันทีเพราะสังเกตเห็นเครื่องหมายดอลลาร์และคำสั่งที่คุ้นเคยจาก Library ภายนอก รวมถึงเมื่อทดสอบรันแล้วโครงสร้างบางส่วนไม่สอดคล้องกับคลาส CSS ที่ออกแบบไว้ วิธีการแก้ไขคือ ผมได้ปฏิเสธโค้ดชุดนั้น แล้วปรับ Prompt ใหม่โดยเน้นย้ำข้อจำกัดว่าต้องใช้ Vanilla JavaScript ล้วน ห้ามใช้ Library ใดๆ ทั้งสิ้น พร้อมทั้งนำโค้ดที่ AI ส่งมาในรอบหลังมาตรวจสอบทีละบรรทัด ทำความเข้าใจการทำงานของคำสั่ง filter และ sort ดั้งเดิมด้วยตนเอง ก่อนนำมาปรับแก้ให้เข้ากับโครงสร้างข้อมูลจริงของกลุ่มเรา

3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว
หลังผ่านกระบวนการพัฒนาโปรเจกต์นี้ร่วมกับเพื่อนๆ ในกลุ่ม สิ่งที่ผมเข้าใจและสามารถทำได้ด้วยตนเองอย่างคล่องแคล่วโดยไม่ต้องพึ่ง AI อีกเลยคือ การเขียนโครงสร้าง Semantic HTML5 ที่ถูกต้องตามหลักการเข้าถึง เช่น การใช้งาน Landmark, การผูก label กับ input ในฟอร์ม และการจัดการ Attribute พื้นฐาน รวมถึงการเขียน CSS Layout ด้วย Flexbox และ Grid เพื่อทำระบบ Responsive ให้รองรับหน้าจอทุกขนาด นอกจากนี้ ผมยังมีความมั่นใจอย่างมากในการเขียน Vanilla JavaScript เพื่อจัดการ DOM Events, การดึงข้อมูลด้วย fetch และการเชื่อมโยงข้อมูลกับ localStorage ซึ่งทำให้ผมพร้อมสำหรับการอธิบายโค้ดทุกส่วนและการสุ่มถามรายบุคคลในวันนำเสนอได้อย่างมั่นใจ
