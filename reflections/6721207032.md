# Reflection รายบุคคลเกี่ยวกับการใช้ AI

**ชื่อ-สกุล:** กมลชนก พงสุระ
**วิชา:** SC17332 Mini Project ธีม “Smart Campus”  
**กลุ่มที่ 6:** Campus Fix-It (ระบบแจ้งปัญหาและติดตามการซ่อมภายในมหาวิทยาลัย)

---

### 1. ส่วนใดของงานที่ฉันใช้ AI ช่วยมากที่สุด เพราะอะไร

ในโปรเจกต์ **Campus Fix-It** นี้ ส่วนที่ฉันใช้ AI ช่วยมากที่สุดคือ **การออกแบบโครงสร้าง logic ใน JavaScript สำหรับระบบตัวกรองหลายเงื่อนไข (Multi-criteria Filtering) และการเขียนฟังก์ชันจัดการ `localStorage`** (เช่น ในหน้า `issues.html` และ `track.html`) 

สาเหตุที่ใช้ AI ในส่วนนี้มากที่สุด เนื่องจากในตอนเริ่มต้นพัฒนา ฉันยังไม่มั่นใจในการเขียนเงื่อนไขซ้อนกันหลายชั้นเพื่อกรองข้อมูลตามหมวดหมู่ อาคาร และสถานะพร้อมกัน รวมถึงการจัดการข้อมูลที่ต้องนำมาผสานกันระหว่างไฟล์ `data/issues.json` กับข้อมูลใหม่ที่บันทึกไว้ใน `localStorage` การให้ AI ช่วยร่างโครงสร้างโค้ดและลำดับตรรกะเบื้องต้น ช่วยให้ฉันมองเห็นภาพรวมการจัดการ DOM Data binding และ Event Listeners ได้ชัดเจนขึ้นมาก ช่วยลดเวลาในการลองผิดลองถูกและทำให้เริ่มต้นพัฒนาฟีเจอร์ F1-F5 ได้รวดเร็วยิ่งขึ้น

---

### 2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร

มีเหตุการณ์ที่ AI ให้คำตอบไม่ตรงตามโจทย์ข้อกำหนดทางเทคนิคอยู่ครับ ในตอนที่ฉันขอคำแนะนำเรื่องการทำฟังก์ชันกรองข้อมูลในรายการปัญหา AI ได้เสนอโค้ดที่ใช้ไลบรารี **jQuery** (เช่น การใช้ `$('#filter').val()` หรือการเลือก DOM Selector แบบย่อ) 

**การรับรู้ปัญหา:**  
ฉันทราบทันทีว่าคำตอบนี้ **ไม่ถูกต้องและผิดข้อกำหนด T9** ของโปรเจกต์อย่างสิ้นเชิง เนื่องจากข้อกำหนด T9 ระบุชัดเจนว่าต้องใช้ **Vanilla HTML, CSS และ JavaScript ล้วนเท่านั้น** ห้ามใช้ Framework หรือ Library ทุกชนิด

**แนวทางการแก้ไข:**  
ฉันปฏิเสธโค้ดดังกล่าวและทำการเขียน Prompt ใหม่โดยระบุเงื่อนไขกำกับอย่างชัดเจนว่า *"ให้ใช้เฉพาะ Vanilla JavaScript (ES6+) ห้ามใช้ jQuery หรือ Library ใดๆ"* จากนั้น AI จึงเจนโค้ดใหม่ที่ใช้ `document.getElementById()`, `Array.prototype.filter()` และ `addEventListener()` ตามมาตรฐาน Vanilla JS หลังจากนั้นฉันได้นำโค้ดมาปรับปรุง ทดสอบเคสที่ค้นหาไม่พบข้อมูล (No Result Found Case) และรีวิวทำความเข้าใจทุกบรรทัดด้วยตนเองก่อนนำไป Commit ลงใน Repository ของกลุ่ม

### 3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว

หลังจากการร่วมพัฒนาและทดสอบระบบจริงกับเพื่อนในกลุ่ม ทำให้ฉันมีความเข้าใจและสามารถทำสิ่งต่อไปนี้ได้ด้วยตนเองโดยไม่ต้องพึ่ง AI:

1. **การสร้างเว็บโครงสร้าง Semantic HTML5 และ Accessibility (a11y):**  
   เข้าใจการเลือกใช้ landmark tags เช่น `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, และ `<footer>` ได้ถูกต้อง รวมถึงการเชื่อมโยง `<label for="...">` เข้ากับ input element เพื่อให้ผ่านเกณฑ์การทดสอบ Lighthouse Accessibility $\ge 90$
   
2. **การจัดการข้อมูลด้วย Fetch API และ LocalStorage:**  
   เข้าใจกระบวนการใช้ `fetch()` ดึงข้อมูลจากไฟล์ JSON ภายนอกมาแสดงผลบน DOM แบบไดนามิก รวมถึงการเขียนฟังก์ชันบันทึกและดึงข้อมูลจาก `localStorage` เพื่อรักษาสถานะของผู้ใช้หลังรีเฟรชหน้าเว็บ เช่น ระบบกดปุ่ม "ฉันก็เจอปัญหานี้ (+1)" ที่มีเงื่อนไขล็อกไม่ให้กดซ้ำในเบราว์เซอร์เดิม (ฟีเจอร์ F5) ซึ่งตอนนี้ฉันสามารถเขียนและ Debug โค้ดส่วนนี้ได้เองอย่างมั่นใจ
