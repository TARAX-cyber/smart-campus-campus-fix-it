# AI Reflection
**ชื่อ: อภิวิชญ์**

ในการทำโปรเจกต์ Campus Fix-It ฉันได้ใช้ AI (Gemini) เป็นเครื่องมือช่วยในการพัฒนาส่วนของ Dashboard โดยเฉพาะการออกแบบ CSS Layout และ UI Components ซึ่งเป็นส่วนที่ฉันใช้ AI ช่วยมากที่สุด เนื่องจากต้องจัดวางกราฟแท่งให้แสดงผลได้อย่างเหมาะสม รวมถึงปรับแต่งหน้าตาของเว็บไซต์ให้สวยงามและรองรับการใช้งานบนหน้าจอที่แตกต่างกัน เช่น การจัดตำแหน่ง Footer ให้อยู่ด้านล่างของหน้าเว็บ และการสร้างปุ่มดูรูปภาพด้วยไอคอน SVG

ระหว่างการทำงานมีบางครั้งที่ผลลัพธ์จาก AI ยังไม่ตรงกับความต้องการ เช่น การปรับแก้กราฟแท่งแล้วเนื้อหายังคงถูกบีบให้แคบลง ฉันจึงนำภาพหน้าจอผลลัพธ์ที่เกิดขึ้นจริงไปให้ AI ช่วยวิเคราะห์เพิ่มเติม และปรับแก้ CSS โดยใช้ max-width และการจัดตำแหน่งให้อยู่กึ่งกลาง นอกจากนี้ยังพบปัญหาการแสดงโค้ด CSS เป็นข้อความบนหน้าเว็บ จึงแก้ไขโดยแยก CSS ออกไปไว้ในไฟล์ภายนอกให้ถูกต้องตามข้อกำหนดของงาน ก่อนนำไปใช้ฉันได้ตรวจสอบโค้ดและทดลองแสดงผลจริง รวมถึงคำนึงถึง Accessibility และข้อกำหนดที่ห้ามใช้ Library ภายนอก

หลังจากทำโปรเจกต์นี้ ฉันมีความเข้าใจเกี่ยวกับการใช้ CSS Flexbox และการกำหนดขนาดองค์ประกอบด้วย CSS มากขึ้น สามารถปรับตำแหน่ง Footer จัดวางกราฟ และใช้ SVG สร้างไอคอนพื้นฐานได้ด้วยตนเอง รวมถึงเข้าใจว่าการใช้ AI เป็นเพียงตัวช่วยในการทำงาน ไม่ใช่การนำคำตอบมาใช้ทั้งหมดโดยไม่ตรวจสอบ ประสบการณ์ครั้งนี้ทำให้ฉันสามารถวิเคราะห์ปัญหาและแก้ไขโค้ดจากผลลัพธ์ที่เกิดขึ้นจริงได้ดีขึ้น
